# No custom PCB

Since v1.3 the device has no circuit board of its own (EDR-19). Every
electronic part is a finished module - FireBeetle 2 ESP32-C6, SEN62, Senseair
Sunrise, SparkFun SGP40, Seeed Grove SHT40, Pololu #2810 switch, Pololu
S9V11E2A regulator, Adafruit LM66200 ideal diode - joined by wires. The ten
resistors and one capacitor that remain are through-hole parts soldered at a
module's pins under heat shrink.

* Wiring list, GPIO map, buses and where each inline part goes:
  `../schematic/NETLIST.md` (generated by `../schematic/design.py`, 510 rule
  checks).
* KiCad-importable netlist: `../schematic/aircheck.net` - if you ever want to
  turn the wiring into a board, start there.
* Step by step: `docs/ASSEMBLY.md`.

The v1.2 carrier board (ACC-1 rev C) is in the git history.
