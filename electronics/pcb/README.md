# No custom PCB

Since v1.3 the device has no circuit board of its own (EDR-19). Every
electronic part is a finished module - FireBeetle 2 ESP32-C6, SEN62, Senseair
Sunrise, SparkFun SGP40, Seeed Grove SHT40, Pololu #2810 switch, Adafruit
#6091 charger, eremit HY2112 BMS, Pololu S9V11E2A regulator, Adafruit LM66200
ideal diode, Adafruit #6050 USB-C socket - joined by wires. The remaining
resistors, capacitors, two BAT43 diodes, the cell fuses and the NTC are
through-hole parts soldered in line under heat shrink (NETLIST.md, "Inline
parts").

* Wiring list, GPIO map, buses and where each inline part goes:
  `../schematic/NETLIST.md` (generated by `../schematic/design.py`, 780 rule
  checks).
* KiCad-importable netlist: `../schematic/aircheck.net` - if you ever want to
  turn the wiring into a board, start there.
* Step by step: `docs/ASSEMBLY.md`.

The v1.2 carrier board (ACC-1 rev C) is in the git history.
